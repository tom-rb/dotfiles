# Writing .md files

 - Do not use a line break in the middle of a sentence, or in the middle of a paragraph. Keep each paragraph on a single line.
 - Always use a single space before the `-` in each top-level list item. This makes for better readability.
 - In a table, align the `|` pipes so the table stays readable in plain text.
